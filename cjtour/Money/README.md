# 💼 旅行社獨立儀表板系統 (Cloudflare Pages + Google Sheets API)

這是一套為旅行社開發的企業級無伺服器 (Serverless) 帳務與出團管理系統。
* **分頁式前端**：採用 HTML5/CSS3 響應式雙欄/三分頁儀表板，設計精美（Glassmorphism 玻璃擬態風格），可直接託管在 **Cloudflare Pages** 獲得您專屬的公網網址。
* **後端資料庫**：基於 **Google 試算表 (Google Sheets)** 與 **Google Apps Script (GAS) Web App API**。
* **財務引擎**：整合了領隊姓名、領隊代墊、業務佣金、退稅等完整欄位，並支援一鍵生成多維度 PDF 報表下載與網頁端互動出團月曆。

## 🛠️ 部署指南

### 第一部分：部署 Google Apps Script API 後端
1. **建立並命名試算表**：在 Google Sheets 中建立空白試算表。
2. **開啟編輯器**：點選上方選單 **「擴充功能」** ➔ **「Apps Script」**。
3. **複製代碼**：清空預設的 `Code.gs`，將本專案的 **[Code.js](file:///Users/chenyanbai/Documents/GitHub/DM/cjtour/Money/Code.js)** 程式碼全部貼上，點選儲存 💾。
4. **初始化工作表**：
   - 回到試算表網頁，重新整理。
   - 點選上方選單 **「💼 旅行社帳務系統」** ➔ **「初始化系統工作表」**（第一次執行需授權）。
   - 初始化成功後，試算表會自動建置所有工作表與包含領隊、代墊、佣金與退稅欄位的範例資料。
5. **部署為 Web 應用程式 (Web App)**：
   - 在 Apps Script 編輯器右上角，點選 **「部署 (Deploy)」** ➔ **「新增部署 (New deployment)」**。
   - 點選齒輪圖示，選擇 **「Web 應用程式 (Web app)」**。
   - **專案說明**：輸入「旅行社帳務 API」。
   - **執行身分**：選擇 **「您的帳戶 (Me)」**。
   - **誰有存取權**：選擇 **「任何人 (Anyone)」** *(⚠️ 請務必選擇 Anyone，否則 Cloudflare 網頁將無法存取)*。
   - 點選 **「部署」** 並**複製產生的「Web 應用程式網址」 (Web App URL)**。

---

### 第二部分：部署前端網頁至 Cloudflare Pages (完全免費)
1. **上傳網頁檔案**：
   - 在本機新建一個資料夾，命名為 `public`。
   - 將本專案中的 **[index.html](file:///Users/chenyanbai/Documents/GitHub/DM/cjtour/Money/Index.html)** 檔案重新命名為小寫的 **`index.html`**，並放到該資料夾中。
2. **Cloudflare Pages 上傳**：
   - 登入 [Cloudflare 控制台](https://dash.cloudflare.com/) ➔ 點選左側 **「Workers 和 Pages」** ➔ 點選 **「Pages」** ➔ **「上傳資產 (Upload assets)」**。
   - 輸入專案名稱，點選「建立專案」。
   - 將 `public` 資料夾拖曳上傳，點選 **「部署網站」**，即可獲得您的專屬 HTTPS 網址！

## 🚀 網頁功能操作說明

開啟您的 Cloudflare 網頁連結，在頂部「API URL」欄位貼上您在第一部分複製的 Apps Script 網址並儲存，網頁即會自動載入資料，您可以使用以下三大分頁功能：

### 📂 第一頁：儀表板 (出團日曆)
* **出團日曆**：日曆會讀取試算表，當日出發的團體會在日期格子內顯示 **「🚌 [團數]團」**。點選切換月份。
* **展開明細**：點選有出團的日期格子，右側（或下方）會立刻展開「出團細節面板」，顯示當天所有出團的訂單編號、產品、旅客人數、負責業務、客戶姓名與金額。

### 📝 第二頁：訂單管理 (表格列表)
* **快捷新增訂單**：點選頂部「展開表單」按鈕可填寫新訂單（包含業務、領隊、客戶、人數、金額、領隊代墊、業務佣金與退稅），點擊「寫入試算表」後會自動計入試算表並計算毛利，且列表與日曆會自動同步更新。
* **列表與排序**：以表格列表方式列出所有訂單。您可以透過下拉選單選擇排序依據：
  - **排序依據**：可選「出發日期」或「報名日期 (訂購日)」。
  - **排序順序**：可選「由新到舊」或「由舊到新」。
  - 排序會即時反應在列表上。

### 📊 第三頁：報表生成 (多維度 PDF 一鍵下載)
系統會自動在您的 Google Drive 中建立一個名叫 `旅行社帳務報表` 的資料夾，產生的報表會存入其中並**自動在您的瀏覽器彈出新分頁開啟 PDF**，供您下載或列印：
1. **業務績效報表 (PDF)**：選擇業務姓名與年份/月份，產生該業務當期訂單數、營業額、旅客人數、代墊、佣金與公司純利 KPI 卡片與明細。
2. **團體收支分析報表 (PDF)**：
   - 下拉選單會自動抓取所有歷史非取消訂單的產品與日期組合（例如：`日本東京五日遊 [2026-06-15]`）。
   - 選擇某個團體後，系統會彙整**同一團所有訂單的總人數、總營業額、總代墊、總佣金與公司淨利**，並列出所有參團訂單明細。
3. **公司財務月報 (PDF)**：選擇年、月，統計公司該月份的營業額、代墊、佣金、行政雜支與月度純利。
4. **公司財務年報 (PDF)**：選擇年份，按月份 1-12 月彙整全年的營業額、成本、雜支與年度淨利，並產出精美圖表。
